# حاسبة الفواتير
## Python Invoice Calculator

**Portfolio Demo Project** | المستوى: **أساسي** | المؤلف: [Eng-7ussamEltayb](https://github.com/Eng-7ussamEltayb)

### الفكرة
حاسبة فاتورة CLI تدعم عناصر متعددة وخصم وضريبة القيمة المضافة وتخرج JSON مرتب.

### التقنيات
Python 3

### المميزات
- حساب المجموع والخصم والضريبة
- إدخال من ملف JSON
- مناسب للدمج مع أنظمة فوترة

### طريقة التشغيل
1. python invoice.py
2. python invoice.py --discount 0.05 --vat 0.15
